# 내 캘린더 (안드로이드 · 갤럭시 폴드7 대응)

PC 바탕화면 캘린더와 같은 기능의 스마트폰 앱입니다. 폴드7은 접으면 폰 화면, 펼치면 달력과 일정·AI 비서를 나란히 보는 두 칸 화면으로 자동 전환됩니다.

## 설치 파일(APK) 만들기 — GitHub Actions (추천)
1. 이 폴더를 GitHub 저장소(예: `my-scheduler-mobile`)에 올립니다.
2. 저장소의 **Actions** 탭 → **Android APK** → **Run workflow**를 누릅니다 (약 15~20분).
   또는 `git tag mobile-v0.1.0 && git push --tags` 하면 Releases에도 올라갑니다.
3. 실행 결과의 **Artifacts**(또는 Releases)에서 APK를 폰으로 받아 엽니다.
   처음에는 "출처를 알 수 없는 앱 설치"를 허용해야 합니다(설정 → 애플리케이션 → 특별한 접근 → 알 수 없는 앱 설치).

다른 방법: Expo 계정이 있으면 `npx eas-cli build -p android --profile preview`로도 APK를 받을 수 있습니다.

## 클라우드 동기화 (PC ↔ 폰) — 처음 한 번만 설정
Firebase 프로젝트 `my-scheduler-e7b5f`에 이미 연결되어 있습니다. 콘솔에서 아래 두 가지만 하세요.

1. **Firestore 보안 규칙 게시 (필수)**
   Firebase 콘솔 → Firestore Database → **규칙** 탭 → 기존 내용을 모두 지우고 `firestore.rules`의 내용을 붙여 넣은 뒤 **게시**.
   "로그인한 본인만 자기 일정을 읽고 쓰기"라는 규칙입니다. 게시하지 않으면 로그인해도 "권한이 없습니다" 오류가 납니다.
2. **(권장) 외부 가입 막기**
   Authentication → **설정** 탭 → **사용자 작업**에서 사용자 가입(생성) 사용 설정을 끕니다. 본인 계정을 먼저 만든 뒤에 하세요.

그다음 PC 캘린더와 폰 앱 **양쪽에서 같은 이메일/비밀번호로 로그인**하면 일정이 실시간으로 맞춰집니다.
- 위젯 제목 옆 점: 초록 = 동기화됨, 노랑 = 연결 중·오프라인, 빨강 = 오류, 회색 = 로그인 안 함 (점을 누르면 설정으로 이동)
- 인터넷이 없어도 쓸 수 있고, 연결되면 자동으로 맞춥니다. 같은 일정을 양쪽에서 고쳤다면 **더 나중에 고친 쪽**이 남습니다.
- 처음 로그인할 때 이 기기에 있던 일정은 서버로 올라가 합쳐집니다. 다른 계정으로 로그인하면 이 기기의 일정은 그 계정의 데이터로 바뀝니다.
- 일정을 지울 때는 반드시 앱에서 지우세요(서버 콘솔에서 직접 지우면 다시 살아날 수 있습니다).
- 앱이 꺼져 있어도 약 15분마다 서버를 확인해 알림과 홈 화면 위젯을 갱신합니다(절전 설정에 따라 늦어질 수 있음). 배터리 설정에서 이 앱을 "제한 없음"으로 두면 더 안정적입니다.
- `firestore.rules`는 PC 캘린더 폴더에 있습니다(같은 규칙을 한 번만 게시하면 됩니다).

## 처음 설정
- **알림:** 처음 실행할 때 알림 권한을 허용하세요.
- **홈 화면 위젯:** 홈 화면을 길게 누름 → 위젯 → "내 캘린더". 모양은 앱 → 설정 → 홈 화면 위젯에서 바꿉니다.
- **AI 비서:** 설정 → AI 비서에 Gemini API 키(aistudio.google.com)를 넣고 "확인"을 누르세요. 녹음 분석은 Gemini만 됩니다.
- **PC 일정 옮기기:** 위 클라우드 동기화로 로그인하면 자동입니다. (로그인 없이 쓸 때만: PC의 `events.json`을 폰으로 보내 앱 설정 → 데이터 → 가져오기)

## 사용법
